# Application screenshots

These images were captured from the running Vextra v1.0.0 extension in Microsoft Edge, using its normal workspace, theme and settings controls.

- `vextra-light.png`: current-video workspace in the light theme.
- `vextra-dark.png`: current-video workspace in the ash-grey dark theme.
- `vextra-markdown-templates.png`: the Markdown template editor.
- `vextra-current-video-transcript.png`: Current Video and the transcript reader.
- `vextra-from-url-transcript.png`: From URL and transcript search.
- `vextra-batch-transcripts.png`: Batch URLs, sample document results and download controls.
- `vextra-markdown-export.png`: the Research preset and rendered Markdown preview.

The populated workspace images use original sample documents labelled “Sample transcript” in their titles, with illustrative chapters and timestamps. They showcase the reader and document tools without attributing sample text to a real YouTube video. The Vextra interface, sample content and these screenshots are covered by the project's MIT Licence.
